# 智能点餐系统

这是一个功能完善的智能点餐系统，采用前后端分离架构，并集成了基于角色的权限控制（RBAC）和多店铺管理功能。

## 主要功能

- **用户管理**: 管理员可以创建、编辑、删除和重置用户密码。
- **角色与权限**: 系统内置“管理员”和“店长”两种角色，并实现了细粒度的权限控制。
- **店铺管理**: 管理员可以创建和管理多个店铺，并为每个店铺分配店长。
- **数据隔离**: 店长登录后，只能查看和管理自己被授权的店铺数据，包括座位、菜品和订单。
- **座位管理**: 管理每个店铺的座位信息，并能为每个座位生成点餐二维码。
- **菜品管理**: 管理每个店铺的菜单，支持图片上传。
- **订单管理**: 店员可以在后台创建和管理订单，关联店铺、座位和菜品。

## 技术栈

### 后端
- **框架**: Spring Boot 3
- **数据库**: PostgreSQL
- **持久层**: MyBatis-Plus
- **安全框架**: Apache Shiro
- **其他**: Lombok, ZXing (二维码生成)

### 前端
- **框架**: Vue 3
- **构建工具**: Vite
- **UI 库**: Naive UI
- **HTTP客户端**: Axios
- **路由**: Vue Router

## 如何运行

### 1. 启动后端服务

确保您已正确配置 `src/main/resources/application.properties` 中的数据库连接信息。

然后，在项目根目录下执行以下命令：

```bash
./mvnw spring-boot:run
```
后端服务将启动在 `http://localhost:8080`。

### 2. 启动前端开发服务器

进入 `frontend` 目录并安装依赖（如果尚未安装）：

```bash
cd frontend
npm install
```

然后，启动开发服务器：

```bash
npm run dev
```
前端应用将运行在 `http://localhost:5173` (或终端提示的其他端口)。

### 3. 访问系统

在浏览器中打开 `http://localhost:5173`。

- **默认管理员账户**:
  - **用户名**: `admin`
  - **密码**: `password`
